# Mapping value alignment

Static GitHub Pages site mapping virtues, risks, training methods and benchmarks disclosed by eight AI companies.

The site is self-contained. Open `index.html` directly or serve the directory with any static web server. The visualisation data is bundled in `data.js`; `data.json` is retained as a reusable machine-readable copy.

To publish with GitHub Pages, select **Deploy from a branch**, then choose the `main` branch and `/ (root)` folder in the repository's Pages settings.
